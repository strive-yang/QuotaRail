# QuotaRail v0.1.0-beta.1

首个公开预发布版本：在 Windows 11 任务栏查看 Codex 剩余额度。

## 功能

- 本机 Codex CLI 真实额度、5H / 7D 剩余比例与重置时间。
- 任务栏额度条、浮窗或仅托盘，点击展开详情。
- 原生设置、主题、位置锁定、5–60 分钟刷新与重连。
- 本地缓存、历史/过期标记、失败退避；默认关闭的自启动。

## 安装

先在 Windows 原生 Codex CLI 登录，再下载解压 `QuotaRail-v0.1.0-beta.1-windows-x64.zip`，双击 `quotarail.exe`，无需管理员权限。包内附 `quota_probe.exe` 诊断工具、说明、本项目及第三方许可证。

对照 `SHA256SUMS.txt` 核对 SHA-256。本版没有代码签名、安装器或自动更新。

## 已知限制

已验证 Windows 11 x64、build 26200.9457、主屏居中底部任务栏、150% 缩放，Codex CLI `0.160.0` / `0.163.0-alpha.10.2`；最低兼容版本未知。

多屏/混合 DPI、Explorer 实际重启、休眠/网络完整恢复、真实登录启动、认证轮换与 24 小时稳定性仍需验证。不支持的任务栏布局可改用托盘或浮窗，请按 Beta 试用。
