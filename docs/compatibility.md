# 兼容性与已知限制

`v0.1.0-beta.1` 是早期预发布，只提供 Windows x64 便携包。

| 范围 | 当前状态 |
| --- | --- |
| 已验证系统 | Windows 11 25H2，build 26200.9457，x64 |
| 已验证任务栏 | 主屏、居中、底部，150% 缩放 |
| 已验证 Codex CLI | `0.160.0`、`0.163.0-alpha.10.2`；最低版本未知 |
| 显示方式 | 默认任务栏内部，可选浮窗和仅托盘 |
| 不支持 | Windows 10、macOS、Linux、WSL、多账户管理 |
| 尚未验证 | ARM64、其他 Windows build、多屏/混合 DPI、自动隐藏、RDP、第三方任务栏 |

这些是验证点，不是所有更新版本都兼容的承诺。额度依赖 CLI、上游协议与账户可见窗口；没有返回的窗口不会编造读数。

## 任务栏与桌面

任务栏模式使用 Explorer 子窗口，不注入 DLL，不移动系统控件，也不自动腾出空间。内部类名/布局可能随 Windows 更新变化。绑定失败、空间不足或 DPI 不兼容时保留托盘，请切换浮窗或仅托盘。

天气预留默认 240 DIP，是可调保守值，不是自动测量。浮窗可能被系统浮层遮挡，不持续抢占全局层级。

实际 Explorer 重启、休眠恢复、断网重连、全屏程序、辅助技术及混合主题组合尚未完整实测。桌面回归曾出现焦点/拖动时序波动；自动检查不覆盖这些交互承诺。

## 刷新、缓存与账户

默认刷新约 300–315 秒，失败后按约 5 / 10 / 20 / 30 分钟退避；没有即时联网恢复通知。可手动刷新或重新连接。外部登录变化不保证立即被常驻会话识别，请主动重连。

默认超过 15 分钟标记过期；修改间隔后使用三个所选周期。历史缓存单独标记，在线账户尚未确认时不作当前数据。曾有本地缓存替换的偶发失败记录，根因尚未复现。

真实令牌自然续期/永久失效、CLI / App 并发轮换、服务端时延和连续 24 小时资源趋势尚未完成完整验证。

## 自启动与发行

自启动仅写当前用户的 QuotaRail 启动项，默认关闭。隔离注册表/命令行测试已覆盖，真实登录、系统禁用策略及移动目录后的登录执行尚未全部实测。移动后重新保存自启动，卸载前先关闭。

首版无安装器、代码签名或自动更新。Windows 可能显示未知发布者提示，请从本仓库 Release 下载并核对校验和，根据自己的判断运行。
